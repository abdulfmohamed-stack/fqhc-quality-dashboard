Example measure query — Controlling High Blood Pressure (CMS165)

Illustrative SQL against a generic encounter/vitals model; table names would map to the eCW reporting schema.

WITH universe AS (            -- UDS patient: ≥1 countable visit in period
  SELECT DISTINCT patient_id FROM encounters
  WHERE enc_date BETWEEN '2026-01-01' AND '2026-12-31'
    AND is_uds_countable = 1
),
denom AS (                    -- age 18–85, HTN dx overlapping period
  SELECT p.patient_id FROM patients p
  JOIN universe u USING (patient_id)
  JOIN problems pr ON pr.patient_id = p.patient_id
   AND pr.value_set = 'Essential Hypertension'
   AND pr.onset_date <= '2026-06-30'
  WHERE DATEDIFF(year, p.dob, '2026-12-31') BETWEEN 18 AND 85
  EXCEPT SELECT patient_id FROM exclusions_cms165   -- hospice, ESRD, frailty…
),
last_bp AS (                  -- most recent BP in period
  SELECT patient_id, systolic, diastolic,
         ROW_NUMBER() OVER (PARTITION BY patient_id
                            ORDER BY vital_date DESC) rn
  FROM vitals WHERE vital_date BETWEEN '2026-01-01' AND '2026-12-31'
)
SELECT COUNT(*)                                        AS denominator,
       SUM(CASE WHEN b.systolic < 140
                 AND b.diastolic < 90 THEN 1 ELSE 0 END) AS numerator
FROM denom d
LEFT JOIN last_bp b ON b.patient_id = d.patient_id AND b.rn = 1;

Synthetic data model

A seeded generator creates patients and appointments. Probabilities shift by site, payer, visit count, CHW enrollment and portal use, and no-shows by lead time, hour, weekday and channel — so the patterns are plausible, not random noise. Re-generating with the same seed returns identical numbers.

National comparison sources

HTN control (63%) and uncontrolled diabetes (30%): HRSA 2022 UDS Trends data brief. Cervical (53%) and colorectal (42%) screening: national UDS figures cited in a NACHC field example (2019–20 reporting). Measures without a cited national figure show only the internal target.
